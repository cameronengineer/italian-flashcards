A card from this deck

Vocabulary · Italian → English

Front
questo
/ˈkwes.to/
Back
this

Agrees with its noun: questo, questa, questi, queste; often quest' before a vowel.

“Questa strada ti irrita, è sempre pieno zeppo.”
word for word: This road you irritates, it-is always full crammed.
— Benvenuti al Sud (2010), 0:20:14

Origin It comes from Vulgar Latin *eccum iste, roughly 'look, that one'. The first part, eccum, also gave Italian 'ecco' ('here it is!'), so questo and ecco are related.

Using dialogue as context

This deck draws on the Italian subtitles of Benvenuti al Sud (2010). Subtitle vocabulary reflects this film’s dialogue and setting; it is not a graded course. The example line and literal English gloss help locate a word in context, while watching and listening provide information that an isolated flashcard cannot.

How to use this deck

  1. Install Anki for your device.
  2. Download the .apkg file above. Pictures and recordings are included.
  3. Open the file with Anki, or choose File → Import on a computer. Check the import summary if you already have related decks.
  4. Choose this deck in Anki and set a daily new-card limit that suits your study.
