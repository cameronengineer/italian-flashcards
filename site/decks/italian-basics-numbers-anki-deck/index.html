Working on easily confused numbers

The deck gives particular attention to teens and tens, including forms such as undici. Try recalling a number in both directions and saying it aloud. A written answer can feel easier than recognising a number in speech; use the recording and practise in contexts such as prices or times alongside the cards.

How to use this deck

  1. Install Anki for your device.
  2. Download the .apkg file above. Pictures and recordings are included.
  3. Open the file with Anki, or choose File → Import on a computer. Check the import summary if you already have related decks.
  4. Choose this deck in Anki and set a daily new-card limit that suits your study.
