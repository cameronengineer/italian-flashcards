Front
il caffè
/kafˈfɛ/
Back
coffee

masculine · plural: i caffè

Invariable: due caffè. Also means a café.

“Gradiresti un caffè? - Non a quest'ora.”
word for word: Would-you-like a coffee? - Not at this-hour.
— Benvenuti al Sud (2010), 0:26:14

Did you know? Order 'un caffè' in Italy and you get an espresso. Ask for a long milky coffee with a caffè latte. The word came via Ottoman Turkish kahve from Arabic qahwa.

How to use this deck

  1. Install Anki for your device.
  2. Download the .apkg file above. Pictures and recordings are included.
  3. Open the file with Anki, or choose File → Import on a computer. Check the import summary if you already have related decks.
  4. Choose this deck in Anki and set a daily new-card limit that suits your study.

Choosing a CILS level

The A1, A2, B1 and B2 decks follow CILS vocabulary lists. Higher levels include words from lower levels, so choose one level to avoid repeats. Compare the four CILS levels. This is an independent study resource, not an official CILS deck or a complete exam course.
