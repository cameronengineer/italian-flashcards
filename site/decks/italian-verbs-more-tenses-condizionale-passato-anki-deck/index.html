Practising the condizionale passato

Recall the conditional form of avere or essere together with the past participle: avremmo visto means “we would have seen”. Check the auxiliary and any agreement required by the verb. This is a compound conditional deck, distinct from the single-word forms in condizionale presente.

Grammar reference: Treccani on the condizionale (in Italian).

How to use this deck

  1. Install Anki for your device.
  2. Download the .apkg file above. Pictures and recordings are included.
  3. Open the file with Anki, or choose File → Import on a computer. Check the import summary if you already have related decks.
  4. Choose this deck in Anki and set a daily new-card limit that suits your study.
