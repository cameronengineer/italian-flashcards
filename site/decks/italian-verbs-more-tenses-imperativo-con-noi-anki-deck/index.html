The imperative with noi

These prompts suggest an action that includes the speaker, as in “let’s think”. The forms overlap with first-person plural present forms, but their function in the prompt is a suggestion or invitation. Read the English cue before recalling the Italian instead of identifying the use from the ending alone.

Grammar reference: Treccani on the imperativo (in Italian).

How to use this deck

  1. Install Anki for your device.
  2. Download the .apkg file above. Pictures and recordings are included.
  3. Open the file with Anki, or choose File → Import on a computer. Check the import summary if you already have related decks.
  4. Choose this deck in Anki and set a daily new-card limit that suits your study.
