# Italian Flashcards

A personal pipeline that turns what you want to learn — CILS levels, class
notes, frequency lists, **the subtitles of a film you're about to watch** —
into Anki cards. It is built word-first: every Italian root word exists
once, gets its grammar from Wiktionary, its card text and a fun fact from
Claude (which also checks the dictionary data), one image from Codex, and
lands in Anki in the order your study plan says you need it.

```
lists.toml ─▶ lexicon (root words: Wiktionary/Kaikki + rules)
                 │
                 ├─▶ AI queue ─ Claude: card prompts, verification, fun facts, verb prompts
                 │            └ Codex:  one image per root
                 ▼
            notes ─▶ Anki (plan → apply: add · update · adopt studied notes · retire · reorder)
                 ▲                                    │
                 └──────── knowledge (what you know) ◀┘ ─▶ study order, movie coverage
```

Everything runs on subscriptions — Claude (`claude -p`) and ChatGPT/Codex
(`codex exec`) — with no pay-as-you-go APIs. When a plan limit is hit the
pipeline pauses and resumes by itself.

---

## Quick start

```sh
claude                 # log in to Claude Code once (Claude subscription)
codex login            # log in to Codex with ChatGPT (images)
echo "sk_..." > .elevenlabs   # ElevenLabs key (audio)

./run.sh               # lexicon → AI queue → notes → Anki → audio
./fc.sh <command>      # any single command, e.g. ./fc.sh movie
```

First time only: `./fc.sh kaikki import` streams the Wiktionary dictionary
(~770 MB download, ~240 MB index in `data/`, nothing else stored).

Prerequisites: Python 3.11+, Node (for Codex), `ffmpeg`, Anki with the
[AnkiConnect](https://ankiweb.net/shared/info/2055492159) add-on (open while
syncing). `run.sh`/`fc.sh` create `.venv` and install from `pyproject.toml`.

## Configuration

| File | Holds |
|---|---|
| `lists.toml` | **What** to learn: every list (kind, input file, deck, type pill, `recognition_only`, `facts`). |
| `plan.toml` | **When**: list priorities (a film with a watch date first), new cards per day, which tenses get full conjugation cards, which extra card types are on. |
| `settings.toml` | **How**: Claude model / effort / concurrency, outage retry, Codex concurrency, audio voice, backups, review / audit / practice / leech defaults. |
| `lexicon/*.jsonl` | The generated lexicon, in git — review AI output as diffs; edit a field and mark it `human` to keep your version forever. |

### List kinds

| kind | Input |
|---|---|
| `csv` | `italian,english` CSV (words, expressions, sentences, sentence stems) |
| `cils` | CILS lists — uses the lemma (`italian_original`) and part of speech (`function`) columns |
| `verbs` | CSV of infinitives |
| `avere` | avere-expressions |
| `subtlex` | top-N verbs / nouns from SUBTLEX-IT |
| `numbers` | generated by rule (0–100, the shapes that teach the system, a fixed random sample) |
| `movie` | Italian subtitles: `inputs/movies/<slug>/subs.it.srt` (gitignored) |

## How it works

### 1 · Lexicon — one record per root word (`lexicon.py`)

Each list row is resolved to a **lexeme** (lemma + part of speech) through
the Kaikki index of English Wiktionary (`kaikki.py`): gender, plural,
adjective forms, full conjugation tables (with irregular verbs flagged),
auxiliary, participles, IPA, Wikimedia Commons recordings, etymology and the
source-language entry it came from (*rubinetto* ← French *robinet* ← *Robin*,
"sheep"). Rules (`italian.py`) do the rest: standard spelling, articles,
articulated prepositions, possessives, compound tenses, numbers, cognate
detection (*-zione = -tion*). A word in several lists is **one** lexeme.

### 2 · AI queue — verify, don't recall (`queue.py`, `tasks.py`)

Durable jobs in study order (the film's words first):

| Job | What Claude / Codex does |
|---|---|
| `lexeme_enrich` | Given the Wiktionary senses, the lists' own glosses and the film line: choose the sense, write the card prompt + hint + register + note, **check the dictionary data** (disagreements → held for review), write a fun fact from the sourced etymology. 15 words per call. |
| `phrase_enrich` | English prompt + hint for sentences and stems. |
| `verb_prompts` | English prompts for the Wiktionary conjugations. |
| `disambiguate` | Hints + "also accepted" when several words share a prompt (*dunque / quindi / perciò*). |
| `image` | Codex draws one flat, text-free illustration per root; every card of that root uses it. Existing images are reused, never deleted. |

Plan limits pause the queue (it sleeps until the reset time it is told);
`./fc.sh work` or the next `./run.sh` carries on where it stopped.

### 3 · Notes (`notes.py`)

One notetype, **Italian Flashcard v4**, with two templates switched on per
note: *Recognition* (Italian → English) and *Production* (English → Italian).
Every card has its root's image. A note goes to Anki only when its content
and image exist.

| Card type | Deck |
|---|---|
| vocab — word, gender · plural or the four adjective forms, IPA, film line, note, fun fact | the root's highest-priority list (`Italian::Movies::…`, `Italian::CILS::A1`, …) |
| phrase — sentences, stems, expressions | same |
| form — conjugations for model verbs (*parlare, credere, dormire, finire*), irregular verbs and the most frequent N; compound tenses built by rule | `Italian::Verbs::<Tense>` |
| nphrase — rule-built article / preposition / possessive drills | `Italian::Noun Phrases` |
| cognate — one card per suffix rule with its examples | `Italian::Cognates` |
| mistake — practice errors | `Italian::Mistakes` |

Lists tag every note (`list::cils-a1`), so filtered decks work too.

### 4 · Anki (`reconcile.py`)

`./fc.sh plan` shows what would change; `./fc.sh apply` does it with targeted
AnkiConnect calls — no `.apkg` imports:

- creates/updates the v4 notetype (template + CSS) and decks;
- adds ready notes, updates changed ones, moves them when their home deck changes;
- **adopts studied notes from before v4**: updated in place, moved to the v4
  deck, and the matching direction of the new note switched off;
- retires unstudied old notes only once their replacement is in Anki (or when
  v4 deliberately has no equivalent); more than the `[sync]` limit needs
  `--allow-retire`;
- **never deletes a studied note** and never touches notes outside the
  pipeline's decks;
- uploads each media file once; never deletes media;
- sets the new-card order from `plan.toml`;
- reads review state back into `knowledge` (unknown / learning / known);
- drift guard: refuses to sync if many notes it put in Anki have vanished
  (wrong profile open?).

### 5 · Audio (`commands/media.py`)

ElevenLabs audio in **study order** (ready notes first), up to
`[run] audio_limit` new files per run. The spoken text drops display variants
(*sono andato/a* → "sono andato").

## Movies

1. Put Italian subtitles in `inputs/movies/<slug>/subs.it.srt` and add a
   `kind = "movie"` list (see the *Le otto montagne* entry).
2. Give it a watch date in `plan.toml`.
3. `./fc.sh movie` → coverage report ("learn 686 roots → 95% of the words")
   and `datasets/<list>.csv` (lemma, count, first appearance, forms heard,
   example line — gitignored).

Subtitles are parsed (ads, tags and hearing-impaired brackets dropped),
lemmatised with SUBTLEX + Wiktionary forms (+ clitic stripping), names are
dropped, and every root gets its count, first appearance and an example
line, which appears on the card. Movie cards are recognition-only by default.

## Commands

```sh
./run.sh                              # everything; flags: --no-ai --no-images --no-sync --allow-retire
./fc.sh check | lexicon | jobs [retry|refresh LIST] | work [--kind K] [--batches N] [--no-images]
./fc.sh notes | plan | apply [--allow-retire] | audio [--per-deck N]
./fc.sh movie [LIST]
./fc.sh practice [--style …] [--length …] [--subjunctive]   # mistakes become cards
./fc.sh learnt | leech [--dry-run] | leech --doctor [--unsuspend]
./fc.sh audit [--deck D] [--limit N] | review | review approve LEMMA… | review approve --all
./fc.sh share [--deck D]              # .apkg for someone else
./fc.sh kaikki import
```

- **review** lists roots Claude disputed (held from Anki until approved),
  failed audits, hidden low-confidence facts and failed jobs.
- **leech --doctor** writes a memory aid onto cards you keep failing.
- **audit** checks ready notes (including fact accuracy), 20 per call.

## Data and safety

| Table | Holds |
|---|---|
| `lexemes`, `senses` | root words and their card text |
| `lists`, `list_items` | list membership, rank, source glosses, film context |
| `ai_jobs` | the queue |
| `form_prompts`, `word_facts`, `mnemonics`, `mistakes` | AI output |
| `v4_notes` | desired Anki notes |
| `knowledge` | what you know (from Anki) |
| `identity` | every note key sent to Anki |
| `entries`, `verb_forms`, `noun_phrases`, `cards` | v3 data, kept to adopt your studied notes |
| `ai_cache` | every AI answer |

Migrations run automatically with a backup first; `backups/` keeps the newest
10 snapshots (`VACUUM INTO`). Media is never deleted. Raw subtitles and movie
datasets never go to git.

Dictionary data: [Wiktionary](https://en.wiktionary.org) via
[kaikki.org](https://kaikki.org), CC BY-SA 4.0 (see `lexicon/README.md`).
Frequency data: [SUBTLEX-IT](https://osf.io/zg7sc/).
